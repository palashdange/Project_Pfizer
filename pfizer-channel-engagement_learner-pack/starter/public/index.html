Checks claims, quarter-end schemes and C&F stock against the trade policy (CO-POL-014) and the C&F agreement. It recommends; a named person decides. Fictional training case: all names and figures are invented.

How to read the results

Code decides every result. Every rule, date, join and sum is checked in code against the case files. The AI only reads pasted text into fields and writes the plain-English explanation; code rejects that explanation if it adds a number or approval wording.

  • Credit recommended every check passed; a person raises the credit note.
  • Reject a policy rule failed (late, repeat, or more packs than sold).
  • Needs a person something can't be confirmed from the data; don't credit yet.
  • Not found not in the data, so nothing was checked.
  • Passed Failed Check Can't check the result of each individual check.
